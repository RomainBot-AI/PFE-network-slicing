# ForecastingDoc

Ce dossier contient uniquement des documents de travail locaux et des archives
d'exploration.

Le seul fichier utile au pipeline final est `ids_relationship.csv`, qui relie
les identifiants CESNET aux institutions/subnets pour construire le panel de
forecasting.

Les notebooks, PDF, prompts et brouillons Markdown ne sont pas la source de
vérité du projet et ne doivent pas être poussés dans GitHub.
